# JSON Parser

A Python utility for converting Scalene JSON profiling data into comprehensible and actionable text file output.

## Overview

This tool parses profiling data generated by Scalene (a Python profiler) from JSON format into a more readable text format, making the performance metrics easier to understand and act upon.

## Prerequisites

- Python (any version)

## Installation

Clone the repository and navigate to the project directory:

```bash
git clone "GIT URL HERE"
cd AI-Energy-Optimization/JSON_Parser
```

## Usage

1. Ensure you have both `parser.py` and `profile.json` in the same directory (JSON_Parser folder).

2. Verify that both files have content (are not empty).

3. Check the file path in `parser.py`:
   - Locate the `file_path` variable at the bottom of the script
   - Make sure it correctly points to your `profile.json` file
   - If you're in the same directory as both files, the path should be the current directory + /profile.json

4. Run the parser:

   **Windows:**
   ```bash
   python parser.py
   ```

   **macOS/Linux:**
   ```bash
   python3 parser.py
   ```

5. The script will generate a formatted text file containing the parsed Scalene profiling data.

## Expected Output

Upon successful execution, the program will convert the JSON profiling data into a formatted text file that presents the performance metrics in a more readable and actionable format.

## Troubleshooting

If you encounter issues:

- Verify both files are in the same directory
- Check that the `file_path` variable is correctly set
- Ensure Python is properly installed and accessible from your command line
